# Evidence and authority

## Evidence

Evidence is kept distinct from inference. A system should be able to show what record or signal supports a conclusion without converting incomplete evidence into an unsupported claim.

## Authority

Proposed action is not execution authority. Approval must be explicit, scoped to the reviewed state, and retained at the human boundary for consequential external action.

## Validation

Validation is part of the operating model: deterministic rules, policy checks, type checks, fixtures, and tests make boundaries inspectable and regressions detectable.

## Publication

Public work samples describe approved, public-safe capability boundaries. They exclude private source, records, identities, credentials, internal paths, and confidential operating material.

## AI-assisted implementation

Matthew defines architecture, requirements, governance, validation criteria, and implementation direction. AI coding agents perform bounded implementation, inspection, testing, and refinement under repository controls and human review.
